# ДЖН1-LANGUAGE

**The Biggest Conlang in the World**

DXN1-Language is a constructed language built on Cyrillic with English mixed in. It is not Russian, not a translation of Russian, and not a cipher. Cyrillic is the foundation — used for speaking, writing, and daily communication. English influences the structure and vocabulary, but the language stands on its own.

DXN1-Language is designed to eventually become a main language.

---

## What Makes DXN1 Different

- **Cyrillic is the base.** You talk, write, and think in Cyrillic.
- **English is mixed in.** Grammar, some vocabulary, and structure come from English, but the language is not English.
- **Four writing modes.** Casual, Standard, Hard, Nightmare — each one compresses further.
- **Tense, negation, questions** are handled by native particles.
- **40,000+ word dictionary** with English headwords mapped to Cyrillic forms.
- **Three-layer affix system.** Prefixes (before), midfixes (inside since v6.63.938), suffixes (after).

## CEFR Learning Path (A1 → C2)

DXN1-Language follows the Common European Framework of Reference for Languages. Each level builds on the previous one with a clear progression from survival basics to near-native mastery.

### A1 — Breakthrough (Survival)

Learn the absolute basics to survive in a DXN1 environment.

| Skill | What You Learn |
|---|---|
| Greetings | привет (hello), пак (bye), спс (thanks) |
| Numbers | 1–100, counting, basic math |
| Pronouns | I, you, he, she, we, they |
| Simple verbs | be, go, have, want, can |
| Basic nouns | food, family, home, body parts |
| Present tense | Use particles to mark simple actions |
| Negation | не before verb ("ю не ид" = you don't go) |

**Goal:** Introduce yourself, ask simple questions, understand basic responses.

---

### A2 — Waystage (Daily Life)

Handle everyday situations and simple conversations.

| Skill | What You Learn |
|---|---|
| Daily routines | wake up, eat, work, sleep, repeat |
| Food & drink | ordering, cooking, restaurant vocab |
| Directions | left, right, straight, near, far |
| Time | today, tomorrow, yesterday, clock time |
| Weather | hot, cold, rain, snow, sunny |
| Shopping | buy, sell, price, cheap, expensive |
| Family & people | mother, father, friend, neighbor |
| Simple past/future | был (past), буд (future) markers |

**Goal:** Navigate daily life, have short conversations, understand simple texts.

### B1 — Threshold (Independent)

Express opinions, describe experiences, handle most travel situations.

| Skill | What You Learn |
|---|---|
| Opinions | "я дум это хороший" (I think this is good) |
| Feelings | happy, sad, angry, excited, tired |

| Health | doctor, medicine, headache, fever |
| Past narratives | telling stories with past tense particles |
| Conditional | "буд бы" constructions |
| Connecting words | but, because, therefore, however |

**Goal:** Work in DXN1, travel independently, express yourself on familiar topics.

## Grammar Overview

| Feature | Method |
|---|---|
| Tense | Particles: `был` (past), `буд` (future), `из` (ongoing), `ду` (completed) |
| Negation | `не` before the verb |
| Questions | `ли` particle or word order |
| Emphasis | `же` |
| Plural | `-s`, `-z`, `-и`, `-ы` depending on style |

**Sentence structure:** Subject + Tense/Aspect + Verb + Object + Place + Mood

**Examples:**
- `я был ид дом` — I went home
- `мы из говор музик` — we are speaking about music
- `ю не лайк это` — you do not like this

## Modes

| Mode | Style |
|---|---|
| Casual | Fast texting, loose spelling, readable |
| Standard | Clean dictionary form |
| Hard | Compressed, mixed-script, harder to skim |
| Nightmare | Extra compressed, symbolic, intentionally messy |
